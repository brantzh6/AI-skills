# 🎭 阿里云百炼数字人项目实施方案

**版本**: v1.0  
**整理时间**: 2026-04-07  
**适用平台**: 阿里云百炼 (Model Studio)

---

## 📋 项目概述

基于阿里云百炼现有能力，构建**端到端数字人视频生成工作流**：
- **形象生成**: 静态图片 → 数字人视频
- **声音复刻**: 10-20 秒样本 → 专属音色
- **口型同步**: 音频驱动 → 口型/表情/动作同步

---

## 🛠️ 阿里云百炼现有能力清单

### 1. 数字人生成 (wan2.2-s2v)

| 能力项 | 说明 |
|--------|------|
| **模型名称** | `wan2.2-s2v` |
| **输入** | 静态图片 + 音频文件 |
| **输出** | 数字人说话/唱歌/表演视频 |
| **分辨率** | 480P / 720P |
| **帧率** | 16 fps |
| **时长** | 由输入音频决定 |
| **支持形象** | 真人（肖像/半身/全身）、卡通人物 |
| **支持场景** | 说话、唱歌、表演 |
| **地域限制** | 仅支持**中国内地（北京）** |
| **计费** | 480P: 0.5 元/秒 | 720P: 0.9 元/秒 |
| **免费额度** | 100 秒（新人） |
| **限流** | 5 RPS，同时 1 个任务 |
| **生成耗时** | 5-10 分钟 |

### 2. 声音复刻 (CosyVoice)

| 能力项 | 说明 |
|--------|------|
| **模型名称** | `cosyvoice-v3.5-plus` / `cosyvoice-v3.5-flash` |
| **声音复刻** | 10-20 秒音频样本 → 高度相似定制音色 |
| **声音设计** | 文本描述 → 定制化音色（如"沉稳的中年男性播音员"） |
| **支持语言** | 中文、英文、日文、韩文、中国方言 |
| **多语言混合** | 支持 |
| **情感控制** | 支持（通过 prompt 描述） |
| **API** | 支持 HTTP API 调用 |

### 3. 文生视频 (wan2.7-t2v)

| 能力项 | 说明 |
|--------|------|
| **模型名称** | `wan2.7-t2v` |
| **输入** | 文本提示词（支持时间戳分镜） |
| **输出** | 10-15 秒短视频 |
| **分辨率** | 720P / 1080P |
| **音频** | 自动匹配环境音/轻音效 |
| **多镜头** | 支持时间戳分镜格式 |

## 🎬 完整工作流方案

### 方案 A：静态数字人播报（推荐入门）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  数字人形象  │     │  声音复刻   │     │  数字人视频  │
│  (静态图片)  │  +  │  (音频文件)  │  →  │  (口型同步)  │
└─────────────┘     └─────────────┘     └─────────────┘
     ↑                     ↑                     ↑
  上传照片            CosyVoice TTS        wan2.2-s2v
  或 AI 生成           或 录音样本          生成视频
```

**适用场景**：
- ✅ 企业宣传片
- ✅ 产品讲解视频
- ✅ 培训课程
- ✅ 新闻播报

**优点**：
- 口型同步精准
- 成本低（0.9 元/秒 720P）
- 生成速度快（5-10 分钟）

**缺点**：
- 动作幅度有限（主要是口型/表情）
- 背景固定

---

### 方案 B：AI 生成数字人短剧（进阶）

```
┌─────────────┐     ┌─────────────┐     ┌─────────────┐
│  分镜脚本   │     │  wan2.7-t2v │     │  后期合成   │
│  (Prompt)   │  →  │  (生成视频)  │  →  │  (剪辑+BGM) │
└─────────────┘     └─────────────┘     └─────────────┘
     ↑                                       ↑
  专业分镜                               Suno/Udio
  六大要素                               生成 BGM
```

**适用场景**：
- ✅ 剧情短片
- ✅ 广告创意
- ✅ 动画故事

**优点**：
- 动作丰富（跑跳/打斗/舞蹈）
- 场景多变
- 电影级镜头语言

**缺点**：
- 口型同步较弱
- 成本较高（按秒计费）
- 生成时间长（3-5 分钟/10 秒）

---

### 方案 C：混合方案（专业级）

```
┌─────────────┐     ┌─────────────┐
│  数字人播报  │  +  │  AI 生成场景  │
│  (wan2.2-s2v)│     │  (wan2.7-t2v)│
└─────────────┘     └─────────────┘
         ↓                ↓
    ┌─────────────────────────┐
    │   FFmpeg 后期合成       │
    │   (抠像 + 合成 + 配乐)    │
    └─────────────────────────┘
              ↓
       ┌─────────────┐
       │  最终成片   │
       └─────────────┘
```

**适用场景**：
- ✅ 高质量宣传片
- ✅ 电影级短片
- ✅ 商业广告

**优点**：
- 口型精准 + 动作丰富
- 电影级画质
- 专业级音质

**缺点**：
- 需要后期技能
- 成本最高
- 制作周期长

## 📝 实施步骤

### 阶段 1：基础能力验证（1-2 天）

**目标**：跑通最小可行性工作流

1. **准备数字人形象图片**
   - 真人照片（正面、清晰、光线均匀）
   - 或 AI 生成（Midjourney/Stable Diffusion）
   - 要求：400-7000 像素，jpg/png/webp 格式

2. **准备音频文件**
   - 格式：mp3/wav
   - 时长：10-60 秒（测试用）
   - 或现场录制（手机录音即可）

3. **调用 wan2.2-s2v API**
   ```python
   # 伪代码示例
   task_id = submit_digital_human_task(
       image_url="https://...",
       audio_url="https://...",
       resolution="720P"
   )
   video_url = poll_task_status(task_id)
   ```

4. **验证输出**
   - 口型同步准确度
   - 表情自然度
   - 视频画质

**交付物**：15-30 秒数字人播报测试视频

---

### 阶段 2：声音复刻集成（2-3 天）

**目标**：实现专属音色数字人

1. **录制声音样本**
   - 时长：10-20 秒清晰语音
   - 内容：平稳朗读（避免情绪波动）
   - 环境：安静无噪音

2. **调用 CosyVoice API**
   ```python
   # 声音复刻
   voice_id = clone_voice(
       sample_audio="https://...",
       model="cosyvoice-v3.5-plus"
   )
   
   # 文字转语音
   tts_audio = text_to_speech(
       text="你好，我是你的 AI 数字人助手",
       voice_id=voice_id
   )
   ```

3. **合成数字人视频**
   - 用复刻的声音驱动数字人

**交付物**：专属音色数字人视频

---

### 阶段 3：多镜头短剧（3-5 天）

**目标**：实现多镜头叙事数字人短剧

1. **编写专业分镜脚本**
   - 使用六大要素格式
   - 明确镜头语言/光影/情绪

2. **调用 wan2.7-t2v 生成**
   - 多镜头 Prompt 格式
   - 时间戳分镜控制

3. **后期合成**
   - 剪辑拼接
   - BGM 添加（Suno/Udio）
   - 音效叠加

**交付物**：1-2 分钟数字人短剧

---

### 阶段 4：自动化工作流（5-7 天）

**目标**：一键生成数字人视频

1. **封装 API 调用**
   - 统一接口
   - 错误处理
   - 进度查询

2. **构建前端界面**
   - 形象上传
   - 文字输入
   - 视频预览

3. **自动化队列**
   - 任务排队
   - 批量处理
   - 结果通知

**交付物**：可商用的数字人视频生成平台

## ⚠️ 当前局限性

### 技术限制

| 问题 | 影响 | 解决方案 |
|------|------|---------|
| **口型同步精度** | 部分音节对不上 | 后期手动调整音频节奏 |
| **表情丰富度** | 主要是口型，表情有限 | 用多镜头切换弥补 |
| **动作幅度** | wan2.2-s2v 动作有限 | 结合 wan2.7-t2v 生成动作镜头 |
| **背景固定** | 无法动态换背景 | 绿幕抠像后期合成 |
| **生成时长** | 5-10 分钟/条 | 批量任务队列处理 |
| **音频能力** | wan2.7 仅环境音 | 后期用 Suno 生成 BGM |

### 成本限制

| 问题 | 影响 | 解决方案 |
|------|------|---------|
| **按秒计费** | 长视频成本高 | 控制单条时长在 30 秒内 |
| **并发限制** | 同时 1 个任务 | 队列批量处理 |
| **分辨率限制** | 最高 720P | 后期超分辨率增强 |
