**版本**: v1.0  
**设计时间**: 2026-04-02  
**目标**: 5-15 分钟 AI 长视频自动生成

---

## 🎯 系统概述

### 两种工作模式

#### 全自动模式
```
用户输入 → 系统全自动处理 → 完整视频输出

适合:
- 快速原型
- 简单故事
- 批量生产
```

#### 半自动模式
```
用户输入 → AI 生成 → 人工确认 → AI 生成 → 人工确认 → ... → 完整视频

适合:
- 专业制作
- 复杂故事
- 高质量要求
```

### 5. 视频生成引擎

#### 批量生成策略

```typescript
interface GenerationBatch {
  id: string;
  name: string;
  shotIds: string[];
  
  // 批次配置
  model: 'wan2.6' | 'kling3.0';
  resolution: '480p' | '720p' | '1080p';
  duration: number;
  
  // 一致性配置
  characterReferences?: string[];
  sceneReferences?: string[];
  seed?: number;
  
  // 生成状态
  status: 'pending' | 'generating' | 'completed' | 'failed';
  progress: number;
  generatedCount: number;
  failedCount: number;
}

// 分批策略
function createBatches(shots: Shot[]): GenerationBatch[] {
  // 按相似度分批，而非按时间顺序
  const batches = [
    { name: '主角特写', shots: shots.filter(s => s.shotType === 'closeup' && s.characters.includes('main')) },
    { name: '主角中景', shots: shots.filter(s => s.shotType === 'medium' && s.characters.includes('main')) },
    { name: '主角全景', shots: shots.filter(s => s.shotType === 'wide' && s.characters.includes('main')) },
    { name: '配角镜头', shots: shots.filter(s => s.characters.some(c => c !== 'main')) },
    { name: '环境镜头', shots: shots.filter(s => s.characters.length === 0) },
    { name: '过渡镜头', shots: shots.filter(s => s.shotType === 'transition') },
  ];
  
  return batches;
}
```

#### 生成流程

```
单镜头生成流程:

1. 准备提示词
   - 基础描述 (镜头描述)
   - 角色描述 (从角色库)
   - 场景描述 (从场景库)
   - 风格/光线/色调

2. 准备参考图
   - 角色参考图 (1-5 张)
   - 场景参考图 (1-3 张)
   - 风格参考图 (可选)

3. 配置生成参数
   - 模型选择
   - 分辨率
   - 时长
   - 种子 (如需要一致性)

4. 发送生成请求
   - 调用视频生成 API
   - 轮询进度
   - 下载结果

5. 质量检查
   - 自动检查 (清晰度/稳定性)
   - 人工审核 (半自动模式)
   - 标记为通过/重生成
```

### 7. 音频处理

#### 配音选项

```
方案 1: 自己录制
  成本：免费
  质量：取决于设备/技巧
  时间：1-2 小时

方案 2: ElevenLabs
  成本：$5-20/月
  质量：专业级
  时间：分钟级
  支持语言：28+

方案 3: HeyGen
  成本：$10-30/月
  质量：专业级
  时间：分钟级
  特色：口型同步

  质量：广播级

```
Step 1: 配音生成

Step 2: 背景音乐
  - AI 生成 (Suno/Udio)
  - 音乐库选择
  - 调整音量/淡入淡出

Step 3: 音效
  - 脚步声
  - 环境音
  - 特殊音效
  - 对白清晰化处理

Step 4: 混音
  - 音量平衡
  - 频率均衡
  - 压缩/限制
  - 导出立体声
