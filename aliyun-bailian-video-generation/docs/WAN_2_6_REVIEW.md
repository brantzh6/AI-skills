## 📝 实际使用技巧

### 提示词优化

```python
# ❌ 简单提示词
prompt = "一只猫在草地上"

# ✅ Wan 2.6 优化提示词
prompt = """
一只毛色光亮的橘猫在阳光明媚的草地上欢快玩耍
镜头：低角度跟随拍摄，景深效果
风格：温暖色调，电影感，3D 卡通
时长：10 秒
"""

# ✅ 多镜头提示词
prompt = """
第 1 个镜头 [0-5 秒] 全景：未来城市空中花园
第 2 个镜头 [5-10 秒] 特写：机器人园丁修剪植物
第 3 个镜头 [10-15 秒] 拉远：展示整个未来城市
风格：科幻，明亮色彩，电影感
"""
```

### 参数设置

```python
# 推荐配置
config = {
    "model": "wan2.6-t2v",
    "size": "1280*720",  # 或 1920*1080
    "duration": 15,  # 最长 15 秒
    "shot_type": "multi",  # 多镜头（关键！）
    "prompt_extend": True,  # 智能改写
    "watermark": False,  # 关闭水印
    "seed": 12345  # 固定种子保持一致性
}
```

### 音频同步

```python
# 方案 1：自动配音
rsp = VideoSynthesis.async_call(
    model='wan2.6-t2v',
    prompt='...',
    duration=15
    # 不传 audio_url，自动生成配音
)

# 方案 2：自定义音频
rsp = VideoSynthesis.async_call(
    model='wan2.6-t2v',
    prompt='...',
    audio_url='https://example.com/audio.mp3',
    duration=15
)
```
