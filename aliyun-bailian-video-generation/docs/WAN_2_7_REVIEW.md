### 2. 9 宫格图生视频 (9-Grid Image-to-Video)

**功能描述**:
```
上传 3x3 排列的 9 张参考图
AI 将每个面板转换为独立场景
场景间平滑过渡
生成连续视频
```

**技术要求**:
- 所有 9 张图相同比率
- 标准格式 (JPG/PNG)
- 建议分辨率 ≥512px (短边)
- 读取顺序：左→右，上→下

**使用场景**:
- ✅ 多场景叙事
- ✅ 时间线展示
- ✅ 产品演示
- ✅ 故事板转视频

**注意事项**:
```
⚠️ 混合横竖图会导致帧率不一致
⚠️ API 参数结构待官方确认
⚠️ 低分辨率图会降低输出质量
```

## 🚀 系统设计更新

### Wan 2.7 集成要点

```typescript
// 新增 Wan 2.7 功能支持
interface Wan27Config {
  // 首尾帧控制
  firstFrame?: string; // URL
  lastFrame?: string; // URL
  
  // 9 宫格图生视频
  imageGrid?: string; // 3x3 grid URL
  
  // 角色 + 声音克隆
  subjectReference?: string; // 角色图 URL
  voiceReference?: string; // 音频 URL
  
  // 指令式编辑
  instructionEditing?: {
    sourceVideo: string;
    instructions: string[];
  };
  
  // 原生音频
  nativeAudio: boolean;
  lipSync: boolean;
  language: string;
}

// 批量生成策略更新
function createBatchesWithWan27(shots: Shot[]): GenerationBatch[] {
  // Wan 2.7 支持更长镜头，减少批次
  const batches = [
    { name: '主角长镜头', shots: shots.filter(s => s.duration > 10) },
    { name: '对话场景', shots: shots.filter(s => s.dialogue) },
    { name: '动作场景', shots: shots.filter(s => s.action === 'high') },
    { name: '环境镜头', shots: shots.filter(s => !s.characters.length) },
  ];
  
  return batches;
}
```
