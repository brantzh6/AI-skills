# 多人同框生成技术指南

**解决打斗、舞蹈等复杂互动场景的视频生成方案**

---

## ⚠️ 核心问题

### 为什么合成方案不适用于打斗场景？

| 问题 | 原因 | 影响 |
|------|------|------|
| **遮挡关系** | 角色互相遮挡 | 合成后边缘不自然 |
| **光影交互** | 角色间阴影投射 | 合成无法模拟 |
| **动作配合** | 攻击/防御时机 | 分步生成无法同步 |
| **透视关系** | 前后景深变化 | 合成透视错误 |
| **物理交互** | 碰撞、接触 | 合成完全无法实现 |

**结论**: 打斗、舞蹈、拥抱等**物理接触场景**必须**一次性生成**

---

## 🎯 解决方案 1：提示词精确控制（推荐）

### 核心思路

使用**详细的多人位置、动作、互动描述**，让模型一次性生成多人同框场景。

### 多人场景提示词模板

```python
multi_character_prompt = """
【场景概述】
咖啡厅内，小艾和阿明正在激烈争吵

【角色 1 - 小艾】
- 位置：画面左侧，距离镜头 3 米
- 姿势：站立，身体前倾，右手食指指向阿明
- 表情：愤怒，眉头紧锁，嘴巴张开
- 服装：白色连衣裙，蓝色腰带（日常造型）
- 发型：黑色长直发，因激动而飘动

【角色 2 - 阿明】
- 位置：画面右侧，距离镜头 3 米
- 姿势：站立，双手摊开，做出解释手势
- 表情：无奈，皱眉，眼神诚恳
- 服装：蓝色 T 恤，牛仔裤（日常造型）
- 发型：黑色短发

【互动关系】
- 两人面对面站立，间距 1.5 米
- 小艾指向阿明的手指清晰可见
- 阿明的双手在胸前，掌心向上
- 两人视线交汇

【镜头】
- 中景，包含两人全身
- 轻微手持晃动，增加紧张感
- 焦点在两人面部之间切换

【环境】
- 背景：咖啡厅内部，其他顾客模糊
- 光照：室内暖光，角色面部有清晰光影
- 色调：温暖但略带紧张氛围

【风格】
3D 卡通，皮克斯风格，电影感，高细节
"""

# 生成
rsp = VideoSynthesis.async_call(
    api_key=api_key,
```

### 关键技巧

#### 1. 明确空间位置

```python
# ❌ 错误：模糊描述
prompt = "小艾和阿明在争吵"

# ✅ 正确：精确位置
prompt = """
小艾：画面左侧，x 坐标 20%，距离镜头 3 米
阿明：画面右侧，x 坐标 80%，距离镜头 3 米
两人间距：1.5 米，面对面站立
"""
```

#### 2. 描述互动细节

```python
# ❌ 错误：简单互动
prompt = "两人在打斗"

# ✅ 正确：详细互动
prompt = """
小艾右拳击向阿明左肩，拳头距离肩膀 10 厘米
阿明左臂抬起格挡，小臂与小艾拳头接触
两人身体接触点有清晰的阴影和褶皱
"""
```

#### 3. 指定视线方向

```python
# ❌ 错误：无视线
prompt = "两人对视"

# ✅ 正确：精确视线
prompt = """
小艾：眼睛看向画面右侧，视线角度 15 度
阿明：眼睛看向画面左侧，视线角度 -15 度
两人视线在画面中央交汇
"""
```

## 🔧 解决方案 5：分镜头 + 有限合成

### 适用场景

- ✅ 远距离对战（无接触）
- ✅ 追逐场景
- ✅ 对话场景
- ❌ 近距离打斗（有接触）
- ❌ 拥抱/舞蹈（身体接触）

### 实现方法

```python
# 场景：两人远距离对峙
scene_parts = [
    {
        "name": "小艾特写",
        "prompt": "小艾举起武器，表情坚定，背景模糊",
        "type": "closeup"
    },
    {
        "name": "阿明特写",
        "prompt": "阿明摆出防御姿势，表情严肃，背景模糊",
        "type": "closeup"
    },
    {
        "name": "全景",
        "prompt": "小艾和阿明相距 10 米对峙，中间空旷场地",
        "type": "wide"
    }

# 分别生成
clips = []
for part in scene_parts:
    rsp = VideoSynthesis.async_call(
        api_key=api_key,

        duration=5,
        seed=12345
    )
    clips.append(wait_and_download(rsp))

# 剪辑在一起（不需要合成，只需拼接）
```

## 📊 方案选择指南

| 场景类型 | 推荐方案 | 理由 |
|---------|---------|------|
| **对话/争吵** | 方案 1：提示词控制 | 无身体接触，提示词可精确描述 |
| **打斗（有接触）** | 方案 2：打斗专用 | 必须一次性生成接触场景 |
| **舞蹈** | 方案 3：舞蹈专用 | 身体接触 + 同步动作 |
| **追逐** | 方案 5：分镜头 | 角色不接触，可分开生成 |
| **拥抱/亲吻** | 方案 2：详细互动 | 必须一次性生成接触 |
| **多人会议** | 方案 1：位置控制 | 无接触，位置固定 |

## ⚠️ 多人同框限制

### 当前模型能力

| 模型 | 最多人数 | 接触场景 | 备注 |
|------|---------|---------|------|
| wan2.6-t2v | 2-3 人 | ⚠️ 有限支持 | 简单互动可生成 |
| wan2.6-i2v | 2 人 | ⚠️ 有限支持 | 基于首帧图像 |
| wan2.6-r2v | 2 人 | ❌ 不支持 | 参考视频单角色 |

### 最佳实践

1. **人数限制**: 最多 2-3 人同框
2. **接触场景**: 必须详细描述接触点
3. **固定种子**: 所有镜头使用相同种子
4. **提示词长度**: 详细描述位置和互动
5. **时长控制**: 复杂互动场景≤10 秒
