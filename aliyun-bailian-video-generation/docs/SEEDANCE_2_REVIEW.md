## 🎯 Seedance 2.0 核心特性

### 技术规格

| 特性 | Seedance 1.5 Pro | **Seedance 2.0** |
|------|-----------------|-----------------|
| 最大分辨率 | 1080p | 480p/720p/**1080p** (最高待定) |
| @ 引用系统 | ❌ | ✅ **9 图 +3 视频 +3 音频** |
| 多镜头叙事 | ❌ | ✅ |
| 视频编辑 (V2V) | 基础 | 高级 |
| 音频 | 单声道 | **立体声** |
| 口型同步 | - | **8+ 语言** |
| 生成模式 | T2V, I2V | T2V, I2V, **V2V** |
| 时长 | 4-12 秒 | **4-15 秒** |
| 架构 | Diffusion Transformer | **Dual-Branch Diffusion Transformer** |

### 独家优势

#### 1. @ 引用系统 (独一无二)

```
最多可附加 12 个文件作为参考:
- 9 张图片 (角色/场景/风格)
- 3 个视频 (动作参考)
- 3 个音频 (音效/音乐)

其他工具对比:
- Kling 3.0: 最多 1-2 张参考图
- Sora 2: 文本提示为主
- Runway: 风格参考 + 角色参考
```

#### 2. 立体声音频同步 (行业最佳)

```
特性:
- 立体声生成 (其他工具为单声道)
- 8+ 语言口型同步 (中文/英文/日文等)
- 双声道音频输出

评测:
"音频同步是 Seedance 2.0 最强的功能"
- 英文口型：自然准确
- 中文口型：同样出色
- 社区反馈一致认可
```

#### 3. 多镜头叙事

```
能力:
- 跨镜头角色一致性
- 场景转换保持连贯
- 15 秒最长输出

示例:
镜头 1: 角色 A 特写 (5 秒)
镜头 2: 角色 B 反应 (5 秒)
镜头 3: 双人互动 (5 秒)
```

## 🎯 推荐使用场景

### ✅ Seedance 2.0 最适合

| 场景 | 理由 |
|------|------|
| **短视频创作者** | 精确控制角色外观、场景构图、音频 |
| **音乐视频制作** | 立体声音频同步 +8 语言口型是亮点功能 |
| **广告公司/工作室** | 多镜头叙事，场景间一致性重要 |
| **视频编辑师** | 想要 AI 辅助编辑 (V2V) 而非纯生成 |
| **开发者** | 需要丰富的 API 输入构建视频管道 |

### ❌ Seedance 2.0 不适合

| 场景 | 理由 |
|------|------|
| **初学者** | 学习曲线陡峭，想要简单的 T2V |
| **人脸为主的内容** | 人脸审查激进，经常拒绝 |
| **中国以外用户** | 需要变通方法，建议用 API |
| **超过 15 秒视频** | 需要拼接片段 |
| **预算有限的爱好者** | 有更简单的工具 |
