# 产品展示场景方案

> 适用于品牌方、电商、广告制作

---

## 方案 1: 咖啡品牌宣传

**目标效果：** 精致、温暖、有品质感的咖啡产品宣传图/视频

### 图片方案

**Prompt：**
```
精致的白色陶瓷咖啡杯放在原木桌面上，杯口袅袅升起热气，
旁边散落着几颗烘焙好的咖啡豆和一片新鲜薄荷叶，
侧逆光温暖光线勾勒出咖啡杯的轮廓和热气的纹理，
暗色调木质背景突出主体，商业产品摄影风格，
超高清，浅景深，Canon EOS R5，100mm 微距镜头
```

**参数：** `--size 1472*1104 --n 1`

### 视频方案

**Prompt：**
```
特写，一杯咖啡放在木桌上，热气袅袅升起，
一缕阳光从侧面缓慢移动照在咖啡杯上，
旁边的咖啡豆微微反射光泽，镜头缓慢推进聚焦杯口
```

**参数：** `--duration 5 --resolution 720P --ratio 16:9`

## 方案 2: 科技产品发布

**目标效果：** 现代、简洁、有科技感的电子产品展示

### 图片方案

**Prompt：**
```
一台银灰色笔记本电脑 45 度角展示在纯黑背景上，
屏幕亮起显示抽象的蓝色渐变壁纸，
底部边缘有一条蓝色 LED 灯带，
专业的产品布光，两侧柔光箱打光，顶部轮廓光，
商业产品摄影，极简风格，Apple 风格
```

**参数：** `--size 1696*960 --n 1`

## 方案 3: 珠宝饰品

**目标效果：** 奢华、精致、闪耀的珠宝展示

### 图片方案

**Prompt：**
```
微距特写，一枚钻石戒指放在深蓝色丝绒展示垫上，
钻石在聚光灯下折射出七彩光芒，
周围散落着几颗碎钻作为陪衬，
专业珠宝摄影布光，多个角度的点光源突出钻石切面，
超高清，精细细节，奢华质感
```

**参数：** `--size 1280*1280 --n 1`
