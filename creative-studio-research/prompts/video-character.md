# 视频生成 Prompt 库

> 适用于阿里云万相 Wan 2.6-t2v / 2.7-t2v 等文生视频模型
> 注意：视频 prompt 与图片不同，需要描述动作和运动

---

## 视频 Prompt 公式

```
[景别] + [主体] + [动作描述] + [环境] + [光影] + [镜头运动] + [氛围/情绪]
```

### 与图片 Prompt 的关键区别

| 维度 | 图片 Prompt | 视频 Prompt |
|------|------------|------------|
| 动作 | 静态姿态 | 必须有明确动作 |
| 时间 | 瞬间 | 需要描述过程 |
| 镜头 | 构图描述 | 必须描述运动 |
| 细节 | 越细越好 | 动作优先级 > 细节 |

## 人物动作

### 1. 海边漫步（⭐⭐⭐⭐⭐）

```
全景，一位穿着白色连衣裙的少女在黄昏的海边沙滩上漫步，
微风吹起她的长发和裙摆，她赤脚踩在湿润的沙滩上，
偶尔低头看脚边退潮留下的贝壳，
夕阳的金色余晖洒在她身上，海面波光粼粼，
镜头从侧面缓慢跟随移动，氛围宁静温柔
```

**参数：** `--duration 5 --resolution 720P --ratio 16:9`
**适用：** 文艺短片、生活方式

### 2. 雨中奔跑（⭐⭐⭐⭐）

```
中景，一个穿着黄色雨衣的小男孩在春雨中的街道上奔跑，
他笑着踩过水坑，溅起水花，
街道两旁是盛开的樱花树，粉色花瓣随风飘落，
镜头从前方缓缓后退跟拍，节奏轻快活泼
```

**参数：** `--duration 5 --resolution 720P --ratio 16:9`

## 风景延时

### 3. 城市日出延时（⭐⭐⭐⭐⭐）

```
大远景，城市天际线从黎明到日出的延时摄影效果，
天空从深蓝色渐变为橙红色再到金色，
城市灯光一盏盏熄灭，阳光照亮摩天大楼的玻璃幕墙，
镜头固定，云层快速流动，光影变化壮观
```

**参数：** `--duration 5 --resolution 720P --ratio 16:9`

## 多角色互动（r2v 模式）

### 4. 咖啡厅对话（⭐⭐⭐⭐⭐）

**wan2.7 写法：**
```
视频1坐在咖啡厅靠窗的位置，面前放着一杯咖啡，
她拿起咖啡杯轻抿一口，微笑着看向对面的视频2，
视频2正在讲述什么，手比划着，表情生动，
午后的阳光透过玻璃窗洒进来，氛围温馨
```

**wan2.6 写法：**
```
character1坐在咖啡厅靠窗位置端着咖啡，微笑着看向对面的character2，
character2正在生动地讲述着什么，手势丰富，
午后阳光透过玻璃洒进来，氛围温馨
```

**参数：** `--mode r2v --ref char1.mp4 --ref char2.mp4 --duration 10`

## 多镜头叙事（r2v + shot-type multi）

### 5. 雨中相遇（⭐⭐⭐⭐⭐）

**分镜描述：**
```
镜头1[3s] 全景：雨中的东京街头，霓虹灯闪烁，
一位撑伞的女孩匆匆走过十字路口
镜头2[2s] 中景：男孩在屋檐下躲雨，
看到女孩后露出惊讶的表情
镜头3[3s] 近景→特写：两人目光相遇，
女孩微微一愣，随后露出惊喜的微笑
镜头4[2s] 全景→中景：男孩走向女孩，
两人在雨中并肩而行，共撑一把伞
```

**Prompt：**
```
视频1撑着透明雨伞在霓虹灯闪烁的雨中街头行走。
图1是屋檐下躲雨的男孩。
视频1匆匆走过，男孩看到她露出惊讶表情，
两人目光相遇，视频1微微一愣然后微笑，
男孩走向她，两人共撑一把伞并肩而行。
多镜头叙事，保持角色一致，日系电影风格
```

**参数：** `--mode r2v --ref girl.mp4 --ref boy.jpg --shot-type multi --duration 10`
