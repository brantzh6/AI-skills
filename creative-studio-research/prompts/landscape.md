# 风景自然 Prompt 库

> 适用于阿里云万相 Wan 2.6-t2i 等文生图模型

---

## 公式

```
[景别] + [主体/场景] + [时间/季节] + [天气/氛围] + [光影] + [色彩] + [风格/画质]
```

---

## 自然风光

### 1. 山间日出（⭐⭐⭐⭐⭐）

```
大远景，连绵的群山在晨雾中若隐若现，山顶云海翻涌，
一轮红日从山脊线上升起，金色阳光穿透云层形成耶稣光，
前景是陡峭的悬崖和几棵松树，
风光摄影，国家地理风格，HDR 色调，超高清，8K
```

**参数：** `--size 1696*960 --n 1`
**适用：** 壁纸、旅游宣传

### 2. 海边日落（⭐⭐⭐⭐⭐）

```
全景，夕阳西下的热带海滩，粉紫色的天空映在平静的海面上，
几棵椰子树的剪影矗立在沙滩上，海浪轻柔地拍打着海岸，
前景是湿润沙滩上反射的夕阳余晖，
旅行摄影风格，温暖色调，长曝光效果，宁静祥和
```

**参数：** `--size 1696*960 --n 1`

### 3. 樱花小径（⭐⭐⭐⭐⭐）

```
中景，一条被樱花树环绕的石板小路，粉色的花瓣如雪般飘落，
阳光透过樱花树的缝隙洒在小路上，形成斑驳的光影，
远处有一个撑着油纸伞的女孩背影，
日系风格，柔和色调，水彩感，梦幻氛围
```

**参数：** `--size 1472*1104 --n 1`

## 城市风光

### 4. 东京雨夜（⭐⭐⭐⭐⭐）

```
全景，东京涩谷的十字路口在雨夜中，霓虹灯倒映在湿漉漉的街道上，
行人撑着透明雨伞匆匆走过，远处的高楼大厦灯火通明，
赛博朋克氛围，蓝紫色调，电影级暗调，浅景深突出前景
```

**参数：** `--size 1696*960 --n 1`
**适用：** 城市宣传、科技品牌

### 5. 上海天际线（⭐⭐⭐⭐）

```
大远景，上海陆家嘴金融区天际线在黄昏时分，
东方明珠塔、上海中心大厦在金色余晖中熠熠生辉，
黄浦江上驶过几艘游船，水面反射着城市灯光，
城市风光摄影，蓝黄金色调，广角镜头
```

**参数：** `--size 1696*960 --n 1`

## 微观自然

### 6. 晨露花朵（⭐⭐⭐⭐）

```
微距特写，一朵沾满晨露的紫色郁金香，
每颗露珠里都倒映着周围的绿叶和天空，
柔和的侧逆光勾勒出花瓣的纹理和透明度，
微距摄影风格，浅景深，精细细节，自然写实
```

**参数：** `--size 1280*1280 --n 1`
