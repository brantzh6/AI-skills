# 多镜头叙事 Prompt 库

> 适用于 wan2.7-t2v（自然语言分镜）和 wan2.7-r2v（参考素材 + 分镜）
> 更新时间：2026-04-06

---

## Wan 2.7 多镜头自然语言格式

wan2.7 的重大升级：**不再需要 `shot_type` 参数**，直接用自然语言描述分镜即可。

### 格式模板

```
第1个镜头[0-X秒] 景别：描述
第2个镜头[X-Y秒] 景别：描述
第3个镜头[Y-Z秒] 景别：描述
```

### 关键规则

1. **时间戳格式**：`[开始秒-结束秒]`，总时长不超过 15 秒
2. **景别关键词**：全景 / 中景 / 近景 / 特写 / 大远景
3. **每个镜头独立描述**：主体、动作、环境、光线
4. **无需 shot_type 参数**：模型自动识别多镜头意图
5. **prompt_extend 建议开启**：智能改写优化分镜描述

## 多镜头 Prompt 模板

### 1. 悬疑侦探（5 镜头）⭐⭐⭐⭐⭐

```
一段紧张刺激的侦探追查故事，展现电影级叙事能力。
第1个镜头[0-3秒] 全景：雨夜的纽约街头，霓虹灯闪烁，一位身穿黑色风衣的侦探快步行走
第2个镜头[3-6秒] 中景：侦探进入一栋老旧建筑，雨水打湿了他的外套，门在他身后缓缓关闭
第3个镜头[6-9秒] 特写：侦探的眼神坚毅专注，远处传来警笛声，他微微皱眉思考
第4个镜头[9-12秒] 中景：侦探在昏暗走廊中小心前行，手电筒照亮前方
第5个镜头[12-15秒] 特写：侦探发现关键线索，脸上露出恍然大悟的表情
```

**参数：** `--model wan2.7-t2v --duration 15 --resolution 720P --ratio 16:9 --prompt_extend true`
**风格标签：** 黑色电影、悬疑、雨夜

### 2. 奇幻冒险（9 镜头·故事板式）⭐⭐⭐⭐⭐

冒险、轻快、神秘、童趣的氛围。
第1个镜头[0-1秒] 全景：奇幻森林里高大树木与光束交错，环境神秘明亮
第2个镜头[1-2秒] 中景：小男孩探险家拨开藤蔓向前探路
第3个镜头[2-3秒] 中景：会飞的小机器人飞在他身边，用蓝光扫描前方
第4个镜头[3-4秒] 特写：一张旧藏宝图在男孩手里展开
第5个镜头[4-5秒] 近景：他露出兴奋表情，眼睛亮起来
第6个镜头[5-6秒] 动作镜头：两人跳过树根和小溪，继续深入森林
第7个镜头[6-7秒] 中景：藤蔓后方露出一个被苔藓覆盖的宝箱
第8个镜头[7-8秒] 特写：宝箱边缘闪出金色光芒

**参数：** `--model wan2.7-r2v --duration 10 --resolution 720P --prompt_extend false`
**参考素材：** 多宫格故事板图（单图参考模式）

## Wan 2.6 vs Wan 2.7 多镜头对比

| 特性 | Wan 2.6 | Wan 2.7 |
|------|---------|---------|
| 参数控制 | `shot_type: "multi"` 必须设置 | 不需要 shot_type，自然语言即可 |
| 分镜格式 | 需要在 prompt 中描述，但依赖参数 | 时间戳格式 `[X-Y秒]` |
| 最长时长 | 通常 10 秒 | 15 秒 |
| 角色引用 | `character1`, `character2` | `视频1`, `图1` |
| prompt_extend | 必须为 true | 建议 true（但可选） |

## 失败案例

### 案例：时间戳重叠

**错误 Prompt：**
```
第1个镜头[0-5秒] 全景：描述...
第2个镜头[4-8秒] 中景：描述...
```
**问题：** 时间戳重叠（4-5秒冲突），模型无法正确解析
**修正：** 确保时间戳连续且不重叠

### 案例：景别缺失

**错误 Prompt：**
```
第1个镜头[0-3秒] 一个人走在街上
```
**问题：** 缺少景别关键词，模型可能理解错误
**修正：** 添加景别，如 `全景：一个人走在街上`
