# 产品摄影 Prompt 库

> 适用于阿里云万相 Wan 2.6-t2i 等文生图模型

---

## 公式

```
[产品主体+细节] + [摆放/角度] + [背景/环境] + [光影/布光] + [构图] + [风格/画质]
```

## 饮品类

### 1. 咖啡（⭐⭐⭐⭐⭐）

```
精致的白色陶瓷咖啡杯放在原木桌面上，杯口袅袅升起热气，
旁边散落着几颗烘焙好的咖啡豆和一片新鲜薄荷叶，
侧逆光温暖光线勾勒出咖啡杯的轮廓和热气的纹理，
暗色调木质背景突出主体，商业产品摄影风格，
超高清，浅景深，Canon EOS R5，100mm 微距镜头
```

**参数：** `--size 1472*1104 --n 1`
**适用：** 咖啡品牌、餐饮宣传

```
几颗新鲜葡萄散落在旁边，柔和的侧光从右上方照来，
酒杯中的红酒呈现深宝石红色，背景是虚化的酒窖木架，
奢侈品产品摄影风格，暗调，高级质感
```
