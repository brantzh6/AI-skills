## 公式

```
[景别] + [主体+年龄+性别+外貌] + [服装] + [动作/姿态] + [表情/眼神] + [环境/背景] + [光影] + [构图] + [风格/画质]
```

## 商业人像

### 1. 商务精英（⭐⭐⭐⭐⭐）

```
近景肖像，35 岁亚洲男性，短黑发，整洁的胡须，穿着深灰色定制西装，
白色衬衫，深色领带，正面微侧看向镜头，自信沉稳的表情，
背景是虚化的现代办公室落地窗，柔和的自然侧光勾勒出面部轮廓，
商业摄影，杂志封面品质，Canon EOS R5，85mm f/1.4 镜头，浅景深
```

**参数：** `--size 1104*1472 --n 1`
**适用：** 企业宣传、LinkedIn 头像

### 2. 时尚女性（⭐⭐⭐⭐⭐）

```
中景，28 岁欧洲女性，金色波浪卷发，穿着酒红色丝绸连衣裙，
站在城市天台上，微风拂过发丝，回眸微笑看着镜头，
背景是黄昏的城市天际线，金色余晖从侧面照来，
时尚杂志风格，Vogue 摄影，柔和的逆光轮廓，高分辨率
```

**参数：** `--size 1104*1472 --n 1`
**适用：** 时尚品牌、社交媒体

坐在窗边的木椅上，手中捧着一本书，微微抬头看向窗外，

## 儿童/家庭

### 7. 儿童写真（⭐⭐⭐⭐⭐）

```
近景，5 岁小女孩，扎着两个小辫子，穿着碎花连衣裙，
蹲在花园里，好奇地看着一只蝴蝶落在手指上，
阳光透过树叶洒下斑驳光影，背景是虚化的花园，
温馨家庭摄影风格，自然光，柔和色调，充满童趣
```

**参数：** `--size 1280*1280 --n 1`

### 8. 情侣写真（⭐⭐⭐⭐）

```
中景，一对年轻情侣，女孩穿着白色连衣裙，男孩穿着休闲衬衫，
在日落的海边沙滩上手牵手漫步，女孩靠在男孩肩上，
夕阳的金色余晖洒在两人身上，海面波光粼粼，
浪漫情侣摄影，温暖色调，逆光剪影效果
```
