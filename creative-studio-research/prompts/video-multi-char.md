## Wan 2.7 多角色引用规则

### 核心引用语法

- **视频角色**：`视频1`、`视频2`、`视频3`（按 media 数组顺序）
- **图像角色**：`图1`、`图2`、`图3`（按 media 数组顺序）
- **简化引用**：如果只有单一素材，可以说 `参考图片` 或 `参考视频`

### Media 数组规则

```json
"media": [
  {"type": "reference_video", "url": "..."},  // → 视频1
  {"type": "reference_video", "url": "..."},  // → 视频2
  {"type": "reference_image", "url": "..."},  // → 图1
  {"type": "reference_image", "url": "..."}   // → 图2
]
```

- 图像 + 视频总数 ≤ 5
- first_frame 最多 1 张（且单独计算）
- 每个参考素材只包含单一主体角色

### 音色引用

通过 `reference_voice` 参数指定音色（wav/mp3，1-10秒）：
- 不指定时，reference_video 默认使用原声
- 同时指定时，reference_voice 优先覆盖

## 多角色 Prompt 模板

### 1. 咖啡厅民谣演奏（3 主体）⭐⭐⭐⭐⭐

```
视频2抱着图3在咖啡厅里弹奏一支舒缓的美式乡村民谣，视频1笑着看着视频2
```

**Media 配置：**
- 视频1：女孩参考视频（倾听者）
- 视频2：男孩参考视频（演奏者）
- 图1：吉他参考图

**参数：** `--model wan2.7-r2v --duration 10 --resolution 720P --prompt_extend false`

### 2. 多人对话场景（2 主体）⭐⭐⭐⭐

```
视频1对视频2说："明天早上我靠你了！" 视频2回答："你放心交给我吧！"
```

**Media 配置：**
- 视频1：角色1参考视频
- 视频2：角色2参考视频

**参数：** `--model wan2.7-r2v --duration 10 --resolution 720P`

### 3. 探险搭档（2 主体 + 场景）⭐⭐⭐⭐

```
参考图片和参考视频一起走进神秘的地下洞穴，参考视频举着火把走在前面，
参考图片跟在后面好奇地四处张望，洞壁上有古老的壁画，
火把的光影在墙壁上跳动，氛围神秘探险
```

**Media 配置：**
- 视频1：探险者1参考视频
- 图1：探险者2参考图

**参数：** `--model wan2.7-r2v --duration 10 --resolution 720P`

### 4. 厨房做饭场景（2 主体）⭐⭐⭐⭐

```
视频1在厨房切菜，视频2在旁边搅拌锅里的汤，
两人偶尔交谈微笑，厨房温馨明亮，
阳光从窗户照进来，蒸汽从锅中升起
```

**Media 配置：**

### 5. 老师与学生（2 主体 + 道具）⭐⭐⭐⭐

```
视频1站在黑板前指着图2（地图），给视频2讲解地理知识，
视频2坐在课桌前认真听讲做笔记，
教室明亮整洁，阳光从窗户照进来
```

**Media 配置：**
- 视频1：老师参考视频

**参数：** `--model wan2.7-r2v --duration 10 --resolution 720P`

## Wan 2.6 vs Wan 2.7 多角色引用对比

| 特性 | Wan 2.6 | Wan 2.7 |
|------|---------|---------|
| 引用语法 | `character1`, `character2` | `视频1`, `图1`, `视频2` |
| 参考素材 | `reference_urls` 数组 | `media` 数组（区分 type） |
| 素材类型 | 不区分图像/视频 | 明确区分 reference_image/reference_video |
| 最大素材数 | 4 个 | 5 个（图像+视频） |
| 音色控制 | 依赖参考视频原声 | 支持 `reference_voice` 参数 |
