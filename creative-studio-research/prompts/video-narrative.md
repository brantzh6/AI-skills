# 情感叙事 Prompt 库

> 适用于 wan2.7-t2v 文生视频（自然语言叙事 + 时间戳分镜）
> 更新时间：2026-04-06

---

## 情感叙事核心原则

1. **情绪先行**：先定情绪基调，再写具体动作
2. **细节承载情感**：不是"她很难过"，而是"她低头咬着嘴唇，眼眶微微泛红"
3. **光影配合情绪**：暖光=温馨，冷光=孤独，逆光=希望
4. **节奏控制**：短句=紧张，长句=舒缓
5. **wan2.7 特性**：可用时间戳 `[X-Y秒]` 精确控制叙事节奏

## 情感叙事 Prompt 模板

### 1. 归乡（温情叙事）⭐⭐⭐⭐⭐

```
第1个镜头[0-3秒] 全景：黄昏的乡间小路上，一个背着旅行包的年轻人远远走来，
金色的夕阳把麦田染成暖橙色，微风拂过麦浪
第2个镜头[3-6秒] 中景：村口老槐树下，一位白发老人站在原地张望，
手搭在额前，身影在余晖中被拉得很长
第3个镜头[6-9秒] 近景：年轻人看到老人，眼眶湿润，加快了脚步
第4个镜头[9-12秒] 特写：老人布满皱纹的脸上绽开笑容，眼角的皱纹像花朵一样舒展
第5个镜头[12-15秒] 全景→中景：两人紧紧拥抱，夕阳把他们的影子融在一起
```

**参数：** `--model wan2.7-t2v --duration 15 --resolution 720P --ratio 16:9 --prompt_extend true`
**情感基调：** 温暖、感动、亲情
**适用：** 家庭品牌广告、节日营销

### 2. 城市孤独（都市情感）⭐⭐⭐⭐

```
深夜的东京公寓，一个年轻女性独自坐在窗前，
窗外是繁华的都市夜景，霓虹灯闪烁但与她无关
她手里捧着一杯已经凉掉的茶，目光空洞地望着远方
桌面上散落着几张未完成的画稿
镜头缓慢推近，捕捉她脸上疲惫又倔强的神情
冷色调，蓝紫色主调，城市的光在玻璃上形成倒影
```

**参数：** `--model wan2.7-t2v --duration 8 --resolution 1080P --ratio 16:9`
**情感基调：** 孤独、倔强、都市
**适用：** 文艺短片、情绪表达

### 3. 童年回忆（怀旧叙事）⭐⭐⭐⭐⭐

```
第1个镜头[0-3秒] 全景：夏日的老家庭院，蝉鸣声中，
阳光透过葡萄架洒下斑驳光影，竹床上铺着凉席
第2个镜头[3-5秒] 中景：一个小男孩和奶奶坐在竹床上，
奶奶摇着蒲扇，小男孩靠在她腿上
第3个镜头[5-7秒] 特写：奶奶的手轻轻抚摸男孩的头发，
蒲扇有节奏地摇动，男孩闭上眼睛露出安心的微笑
第4个镜头[7-10秒] 全景→拉远：镜头缓缓拉远，
庭院被温暖的金色光线包裹，时光仿佛定格
```

**参数：** `--model wan2.7-t2v --duration 10 --resolution 720P --ratio 16:9 --prompt_extend true`
**情感基调：** 怀旧、温暖、童年
**适用：** 节日营销、品牌形象片

### 4. 毕业告别（青春情感）⭐⭐⭐⭐

```
第1个镜头[0-3秒] 全景：六月的大学校园，林荫道上铺满落叶，
四个穿着学士服的毕业生并肩走着
第2个镜头[3-5秒] 中景：他们在标志性的校门前停下，
互相整理学士帽和流苏
第3个镜头[5-8秒] 特写→中景：其中一位女孩拿出手机自拍，
四个人挤进镜头，有人笑有人偷偷抹眼泪
第4个镜头[8-10秒] 全景→升：镜头缓缓升起，
四个人并肩走向远方，阳光从树梢间洒下来
```

**参数：** `--model wan2.7-t2v --duration 10 --resolution 720P --prompt_extend true`
**情感基调：** 青春、不舍、希望

### 5. 久别重逢（戏剧性情感）⭐⭐⭐⭐⭐

```
拥挤的机场到达大厅，人来人往
一个穿着灰色大衣的女人站在接机口，紧张地搓着手
自动门打开，一个男人拖着行李箱走出来
两人同时看到了对方——
特写：女人的手捂住嘴，眼眶瞬间红了
特写：男人放下行李，大步走来
中景：两人紧紧拥抱，周围的人群模糊成背景
暖光，逆光，镜头缓慢旋转环绕
```

**参数：** `--model wan2.7-t2v --duration 10 --resolution 720P --ratio 16:9`
**情感基调：** 激动、感动、爱情

## 情感词汇速查表

| 情感 | 核心关键词 | 光线建议 | 镜头建议 |
|------|-----------|---------|---------|
| **温暖** | 微笑、拥抱、金色、余晖 | 暖光、逆光 | 缓慢推进 |
| **孤独** | 独自、远方、冷色、倒影 | 冷色调、侧光 | 固定镜头 |
| **紧张** | 急促、奔跑、呼吸、汗水 | 高对比度 | 手持抖动 |
| **希望** | 日出、光线、抬头、微笑 | 晨光、逆光 | 缓慢升起 |
| **悲伤** | 眼泪、低头、沉默、背影 | 阴柔光、冷色 | 缓慢拉远 |
| **喜悦** | 奔跑、笑声、跳跃、阳光 | 明亮、高饱和度 | 跟随移动 |
