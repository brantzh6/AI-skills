# AI Skills

Custom OpenClaw skills collection.

## Skills

| Skill | Description |
|-------|-------------|
| **aliyun-bailian-doc-research** | 阿里云百炼文档研究方法，系统性地挖掘独立文档页面、验证链接有效性、提取模型信息和构建完整知识体系 |
| **aliyun-bailian-sync** | 阿里云百炼文档同步工具 |
| **aliyun-bailian-video-generation** | 阿里云百炼视频生成技能包，支持文生视频、图生视频、参考生视频、数字人、视频编辑等 |
| **notion** | Notion API for creating and managing pages, databases, and blocks |
| **tts** | Generate speech from text using Aliyun TTS |

## Usage

Install via ClawHub or copy the skill folders to your OpenClaw workspace.
