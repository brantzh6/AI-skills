# Content Studio — 内容创作与管理体系

> **不是剧本生成器，是一个完整的创作系统。**
> 从灵感采集→故事分析→角色设计→世界观构建→剧本创作→审校迭代→平台分发

---

## 核心理念

### 一、先有人，后有故事

所有好故事的起点不是"什么情节"，而是"什么人"。角色不是推动情节的工具，**情节是角色做选择的结果**。

```
错误路径：想一个情节 → 找个人来演
正确路径：理解一个人 → 看他做什么选择 → 那就是情节
```

### 二、结构是骨架，情感是血肉

结构工具（Save the Cat / Hero's Journey）是**诊断工具**，不是**生成公式**。

- ❌ "按15节拍填内容" → 机械、可预测、没有灵魂
- ✅ "先找到角色的情感需求 → 用结构检验节奏是否合理" → 有温度、有意外、有共鸣

### 三、积累 > 技巧

没有大量阅读和观影积累，再好的技巧框架也是空壳。content-studio 的第一功能是**建立和维护创作灵感库**。

## 叙事理论参考库

### 经典叙事结构（诊断用）

| 框架 | 核心思想 | 适用场景 | 关键节拍 |
|------|----------|----------|----------|
| **Save the Cat (15节拍)** | Blake Snyder 的商业片节拍表 | 电影/短剧节奏把控 | 开场画面(1) → 主题声明(5) → 设置(1-10) → 催化剂(12) → 犹豫(12-25) → 第二幕进入(25) → B故事(30) → 游戏(30-55) → 中点(55) → 坏人靠近(55-75) → 一切失去(75) → 灵魂黑夜(75-85) → 第三幕进入(85) → 结局(85-110) → 最终画面(110) |
| **Hero's Journey (12阶段)** | Joseph Campbell / Vogler 的英雄之旅 | 冒险/成长类 | 平凡世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越门槛 → 考验/盟友/敌人 → 接近洞穴 → 严峻考验 → 获得奖赏 → 返回路 → 复活 → 带着灵药回归 |
| **Kishōtenketsu (起承转合)** | 东亚四段式叙事，无对抗也可成立 | 日常/温情/文艺 | 起(介绍) → 承(发展) → 转(意外转折) → 合(融合收束) |
| **Fichtean Curve** | 以连续危机推进，无铺垫直接进入冲突 | 惊悚/悬疑/短篇 | 直接危机 → 连续升级危机 → 高潮 → 收尾 |
| **Seven-Point Structure** | Dan Wells 七点结构，强调角色变化 | 角色驱动型故事 | 钩子 → 转折点1 → 压力点1 → 中点 → 压力点2 → 转折点2 → 结局 |

### 角色弧光模型

| 弧光类型 | 定义 | 例子 | 情感机制 |
|----------|------|------|----------|
| **正向弧光** | 角色从缺陷走向成长 | 《玩具总动员》胡迪从嫉妒到无私 | 观众看到"可能性"，获得希望感 |
| **负向弧光** | 角色从光明堕入黑暗 | 《教父》迈克尔从正直到冷血 | 观众看到"警示"，获得恐惧与反思 |
| **平坦弧光** | 角色信念不变，改变周围世界 | 《阿甘正传》阿甘始终纯真 | 观众看到"坚守的力量"，获得安慰 |
| **反讽弧光** | 角色获得想要的，却失去需要的 | 《公民凯恩》拥有世界但失去爱 | 观众看到"欲望的代价"，获得悲剧感 |

### 情感曲线设计

好故事的情感不是线性的，而是**波浪式推进**：

```
情感强度
    ↑
 高 |     ╭─╮         ╭──╮
    |    ╱   ╲       ╱    ╲       ╭── 高潮
    |   ╱     ╲  ╱  ╱      ╲    ╱
中  |  ╱       ╲╱  ╱        ╲  ╱
    | ╱        /\ ╱          ╲╱
低  |╱        /  ╲╱            ← 结局余韵
    |        / 初始状态
    +────────────────────────→ 时间
    开场   中点   最低谷  高潮
```

**关键原则：**
1. **每次低谷必须比上一次更深**（stakes 递增）
2. **高潮前的"灵魂黑夜"必须足够黑**（否则高潮无感）
3. **结局不能回到初始状态**（角色必须改变或世界必须改变）

## 创作灵感采集体系

### 灵感来源矩阵

| 来源 | 采集内容 | 频率 | 存储位置 |
|------|----------|------|----------|
| **经典电影/剧集** | 叙事结构、角色弧光、情感转折点 | 每周1-2部 | `inspiration/film-notes/` |
| **网络文学平台** | 开头钩子、节奏控制、爽点设计 | 每日浏览 | `inspiration/web-novel/` |
| **知乎盐选** | 反套路开头、反转设计、情感共鸣点 | 每日浏览 | `inspiration/zhihu/` |
| **真实新闻/故事** | 人性复杂性、荒诞与真实 | 随时记录 | `inspiration/real-life/` |
| **心理学/哲学** | 角色动机深度、主题挖掘 | 持续积累 | `reference/psychology/` |

### 知乎盐选爆款拆解（核心技法）

**开头钩子公式：**
1. **反常识开局**：打破读者预期
   - "我死了以后，才发现老公早就知道我会死。"
   - "面试那天，我发现面试官是我十年前抛弃的女儿。"
   
2. **极致情境**：把角色推到极端
   - "被困在电梯里36小时，我才发现旁边这个沉默的男人是我前任。"
   
3. **悬念+情感双重钩子**：
   - "我妈去世那天，银行打来电话说她卡里有三千万。"

**结构节奏：**
- 前300字必须抓住读者（钩子）
- 每800-1000字一个小转折
- 每3000字一个大反转
- 结尾必须有"意料之外，情理之中"的收束

### 起点中文网核心技法

**黄金三章原则：**
1. 第一章：建立主角人设+展示核心矛盾/金手指
2. 第二章：制造第一个冲突+展示主角应对方式
3. 第三章：小高潮收尾+留下悬念

**爽点设计：**
- **预期违背**：所有人都觉得主角不行，结果他行
- **信息差**：读者知道别人不知道的事，制造"看你们装"的快感
- **延迟满足**：先压抑再释放，压抑越深释放越爽
- **降维打击**：用高级能力解决低级问题

### 豆瓣高分作品共性

1. **主题先行**：先有一个想探讨的人性/社会问题
2. **角色复杂性**：没有纯粹的好人和坏人
3. **留白**：不把所有话说完，留给观众思考空间
4. **细节叙事**：用一个细节代替一段对话

## 内容管理工作流

### Phase 1: 概念孵化 (Ideation)

```
输入：一个想法/情感/画面
↓
1. 这个故事的"核心情感"是什么？（孤独？勇气？救赎？）
2. 谁在经历这种情感？（角色雏形）
3. 什么情境会最大化这种情感？（世界观/设定）
4. 角色必须做出什么艰难选择？（核心冲突）
↓
输出：一段话的故事概述（logline）
```

**Logline 公式：**
> [角色] + [困境/目标] + [阻碍/代价] + [情感核心]

示例：*"一只害怕被遗弃的流浪猫，为了守护一个快要倒闭的社区图书馆，必须学会相信人类，却发现最危险的不是被抛弃，而是主动选择离开。"*

### Phase 2: 角色圣经 (Character Bible)

每个主要角色必须回答：

| 问题 | 目的 |
|------|------|
| 他/她最想要什么？（want） | 驱动情节的目标 |
| 他/她真正需要什么？（need） | 角色弧光的方向 |
| 他/她最害怕什么？（fear） | 制造冲突和张力 |
| 他/她的谎言是什么？（lie） | 角色对自己的错误认知 |
| 他/她的伤口是什么？（ghost/wound） | 过去事件塑造的缺陷 |
| 他/她会怎么说话？（voice） | 对白辨识度 |
| 什么情境下他/她会做最不像自己的事？ | 揭示角色深度的关键时刻 |

### Phase 3: 故事节拍 (Beat Sheet)

基于角色弧光设计节拍，而非反向：

```
1. 开场画面：展示角色在"谎言"中的状态
2. 催化剂：打破角色舒适区的事件
3. 犹豫：角色拒绝改变（因为害怕）
4. 跨越门槛：角色被迫/选择进入新世界
5. B故事：引入情感线/关系线（通常是主题载体）
6. 游戏：角色用旧方式应对新世界（有成功有失败）
7. 中点：伪胜利/伪失败 + 真实 stakes 曝光
8. 坏人逼近：外部压力和内部矛盾同时加剧
9. 一切失去：角色失去最在意的东西
10. 灵魂黑夜：角色面对自己的"谎言"
11. 觉醒：角色选择"需要"而非"想要"
12. 高潮：角色用新的自己做出选择
13. 结局画面：展示角色的改变（与开场对比）
```

### Phase 4: 剧本创作 (Drafting)

**场景写作原则：**
1. **每个场景必须有冲突**：哪怕只是内在冲突
2. **晚进早出**：场景从尽可能晚的点开始，在悬念中结束
3. **展示而非告知**：用行动和选择代替解释
4. **对白是冰山一角**：好的对白下藏着没说出口的东西

### Phase 5: 审校迭代 (Braintrust Review)

**10项审查清单：**

| # | 审查项 | 不合格的表现 |
|---|--------|-------------|
| 1 | 角色驱动 | 情节推动角色，而非角色驱动情节 |
| 2 | 情感弧线 | 情感没有变化或变化不合理 |
| 3 | 冲突层级 | 没有从内在→人际→外部逐层升级 |
| 4 | 选择与代价 | 角色没有做过艰难选择 |
| 5 | 主题一致性 | 故事没有探讨一个核心问题 |
| 6 | 开场钩子 | 前30秒/前300字不能吸引人 |
| 7 | 中点转折 | 中点没有改变故事方向或 stakes |
| 8 | 灵魂黑夜 | 高潮前的低谷不够深 |
| 9 | 结局对比 | 结局和开场没有形成有意义的对照 |
| 10 | 留白空间 | 没有留给观众/读者思考和感受的空间 |

## 使用命令

### `/content-studio new [项目名]`
创建新项目，包含完整的目录结构和初始文件。

### `/content-studio analyze [作品名]`
拆解一部作品（电影/小说/短剧），输出结构分析、角色分析、情感曲线。

### `/content-studio capture [灵感来源] [内容]`
采集灵感并分类存储到灵感库。

### `/content-studio review [剧本名]`
用10项审查清单对剧本进行诊断。

### `/content-studio inspiration`
浏览灵感库，随机推荐或按标签搜索。
