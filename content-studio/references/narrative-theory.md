# 叙事理论速查手册

## 一、故事的核心

> **故事不是"发生了什么事"，而是"角色在压力下做了什么选择"。**

```
好故事 = 角色 + 困境 + 选择 + 后果
```

### 角色驱动的五个核心要素

| 要素 | 定义 | 功能 | 示例（胖福） |
|------|------|------|-------------|
| **Want** | 角色表面想要的 | 驱动情节前进 | "我想离开家去看看宇宙" |
| **Need** | 角色真正需要的 | 角色弧光的方向 | "学会相信别人，不再独自承担" |
| **Lie** | 角色相信的谎言 | 阻碍成长的心理壁垒 | "我只能靠自己，依赖别人会被伤害" |
| **Wound** | 过去的创伤 | 解释Lie的来源 | 曾被前任主人遗弃 |
| **Fear** | 角色最害怕的 | 制造冲突和张力 | "做出错误的选择，伤害信任我的人" |

## 二、叙事结构速查

### 1. 三幕剧（最基础）

```
第一幕（25%）      第二幕（50%）       第三幕（25%）
建置               对抗                解决
│                 │                  │
├─ 日常世界        ├─ 尝试与失败       ├─ 最终对决
├─ 催化剂          ├─ 中点转折         ├─ 新常态
└─ 进入第二幕      └─ 一切失去         └─ 主题呼应
```

**关键规则：**
- 每一幕结束时，情况必须比开始时更糟
- 角色必须在每一幕做出**主动选择**（不是被动挨打）

### 2. Save the Cat 十五节拍

| 节拍 | 位置 | 关键问题 |
|------|------|----------|
| 开场画面 | 1% | 角色现在的生活是什么样的？ |
| 主题声明 | 5% | 有人说了什么话暗示角色要学的功课？ |
| 铺垫 | 1-10% | 角色缺什么？生活哪里不对？ |
| 催化剂 | 12% | 什么事件让旧生活无法继续？ |
| 犹豫 | 12-25% | 为什么角色不想/不敢改变？ |
| 进入第二幕 | 25% | 角色做了什么不可逆的决定？ |
| B故事 | 30% | 谁将教会角色功课？ |
| 游戏 | 30-55% | 观众为什么想看这部作品？ |
| 中点 | 55% | 什么让stakes突然变高？ |
| 坏人逼近 | 55-75% | 什么在变糟？角色在逃避什么？ |
| 一切失去 | 75% | 角色失去了什么？ |
| 灵魂黑夜 | 75-85% | 角色最低谷是什么状态？ |
| 进入第三幕 | 85% | 角色明白了什么？ |
| 结局 | 85-110% | 角色做了什么与开场不同的事？ |
| 最终画面 | 110% | 角色变成了什么样？ |

### 3. 英雄之旅（12阶段）

平凡世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越门槛 → 考验/盟友/敌人 → 接近洞穴 → 严峻考验 → 获得奖赏 → 返回路 → 复活 → 带着灵药回归

### 4. 起承转合（东亚四段式）

| 阶段 | 功能 | 特点 |
|------|------|------|
| 起 | 介绍 | 建立预期 |
| 承 | 发展 | 推进但不颠覆 |
| 转 | 意外转折 | 打破预期，引入新视角（**不依赖对抗**） |
| 合 | 收束 | 带着新理解融合前三段 |

**与三幕剧的核心区别：** 起承转合可以没有对抗性冲突，靠"理解的变化"推进故事。

### 5. Fichtean Curve（连续危机）

直接危机 → 连续升级危机 → 高潮 → 收尾

**适用：** 惊悚/悬疑/短篇 — 没有铺垫，直接进入冲突。

### 6. 七点结构（Dan Wells）

钩子 → 转折点1（被动→主动） → 压力点1 → 中点 → 压力点2 → 转折点2（获得最后工具/认识） → 结局

## 三、角色弧光模型

### 四种弧光

| 类型 | 变化方向 | 情感效果 | 适用 | 例子 |
|------|----------|----------|------|------|
| 正向 | 缺陷 → 成长 | 希望、鼓舞 | 成长故事 | 《玩具总动员》胡迪 |
| 负向 | 光明 → 堕落 | 警醒、悲剧 | 黑帮/心理惊悚 | 《教父》迈克尔 |
| 平坦 | 不变，改变世界 | 信念的力量 | 超级英雄/福尔摩斯 | 《阿甘正传》 |
| 反讽 | 得到想要的，失去需要的 | 悲剧感 | 文学/艺术电影 | 《公民凯恩》 |

### 弧光阶段（以正向弧光为例）

```
1. 开场：在谎言(Lie)中生活
   ↓
2. 催化剂：谎言开始受到挑战
   ↓
3. 抗拒：紧紧抓住谎言（因为害怕）
   ↓
4. 中点：瞥见真相(Truth)，但不敢接受
   ↓
5. 倒退：恐惧被触发，退回谎言
   ↓
6. 灵魂黑夜：谎言彻底失效，必须面对真相
   ↓
7. 觉醒：接受真相
   ↓
8. 高潮：基于真相做出选择（与开场相反）
   ↓
9. 结局：以新的方式生活
```

## 四、情感曲线

### 设计原则

```
情感强度
  高 |     ╭──╮              ╭── 高潮
     |    ╱    ╲            ╱
  中 |   ╱      ╲    ╭─╮  ╱
     |  ╱        ╲  ╱   ╲╱
  低 | ╱          ╲╱    灵魂黑夜
     |╱           /\
     └─────────────────────→ 时间
    开场      中点       结局
```

**三条铁律：**
1. 每次低谷必须比上一次更深（stakes 递增）
2. 高潮前的"灵魂黑夜"必须足够黑（否则高潮无感）
3. 结局不能回到开场状态（角色或世界必须改变）

### 情感触发机制

| 情感 | 触发方式 | 示例 |
|------|----------|------|
| 同情 | 展示脆弱/不公 | 被欺负但善良的角色 |
| 紧张 | 信息差+时间压力 | 危险靠近但角色不知道 |
| 惊喜 | 打破预期但合理 | 反转 |
| 悲伤 | 失去 + 未完成 | "我还没告诉他我爱他" |
| 满足 | 伏笔回收 | 前面埋的线索终于用上 |
| 希望 | 低谷中的微光 | "也许还有机会" |

## 五、场景写作

### 每个场景三要素

1. **目标** — 角色在这个场景想要什么
2. **障碍** — 什么阻止了角色
3. **转折** — 场景结束时情况必须变化

### 进出原则

- **晚进**：从冲突已经开始的地方进（跳过寒暄）
- **早出**：在悬念/情感高点出（不要在事情解决后还拖）

### 展示而非告知

| ❌ 告知 | ✅ 展示 |
|---------|---------|
| "胖福很害怕" | "胖福的爪子抓紧地面，耳朵向后贴紧" |
| "他们关系很好" | "她自然地把他杯子里的凉水换成了温水" |
| "他很愤怒" | "他把钥匙扔在桌上，声音比平时大了三倍" |

## 六、对白写作

### 四条原则

1. 每个角色有**独特声音**（遮住名字也能分清谁在说话）
2. 推动情节**或**揭示角色（废话删掉）
3. 有**潜台词**（说的≠想说的）
4. 避免"信息倾销"（角色互相告知已知信息）

### 潜台词示例

```
表面：
A: "你来了。"
B: "嗯。"
A: "外面冷吗？"
B: "还好。"

潜台词：
A: 我一直在等你，我很担心。
B: 我知道你在等，我差点不来了。
```

## 七、伏笔与回收

**契诃夫之枪：** 如果第一幕出现了一把枪，第三幕它必须开火。

### 伏笔类型

| 类型 | 方法 | 示例 |
|------|------|------|
| 视觉伏笔 | 画面中的物品 | 开场的旧照片在结尾有意义 |
| 对话伏笔 | 看似随意的话 | "我从不后悔" → 后来后悔了 |
| 行为伏笔 | 习惯动作 | 关键时刻打破习惯 = 角色变了 |
| 情感伏笔 | 早期建立的情感连接 | 后期产生后果 |

### 回收原则

- 不能太近（明显）也不能太远（被遗忘）
- 回收时要有**情感冲击**，不只是信息揭示
- 最好的回收：读者回头想"原来早就有线索"

## 八、冲突层级

好故事同时运作**三层冲突**：

| 层级 | 描述 | 胖福示例 |
|------|------|----------|
| **内在** | 角色内心的矛盾 | 想冒险 vs 害怕被抛弃 |
| **人际** | 角色之间的矛盾 | 胖福 vs 同伴的分歧 |
| **外部** | 与环境的对抗 | 生存危机、时间压力 |

## 九、Logline 公式

> **[角色] + [困境/目标] + [阻碍/代价] + [情感核心]**

### 好 vs 差

| ❌ 差 | ✅ 好 |
|-------|-------|
| "一只猫去太空冒险" | "一只害怕被遗弃的流浪猫，为了守护一个快要倒闭的社区图书馆，必须学会相信人类，却发现最危险的不是被抛弃，而是主动选择离开。" |
| "英雄打败了魔王" | "一个不敢面对过去的老兵，被迫保护他曾经背叛过的人的儿子，必须在牺牲自己和再次逃跑之间做出选择。" |
