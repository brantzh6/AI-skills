## 📊 核心挑战

### 长视频生成难点

| 挑战 | 描述 | 严重程度 |
|------|------|---------|
| **角色一致性** | 多镜头中角色外观漂移 | 🔴 高 |
| **场景一致性** | 场景/背景变化不连贯 | 🔴 高 |
| **风格一致性** | 视觉风格不统一 | 🟡 中 |
| **时长限制** | 单次生成 5-15 秒上限 | 🟡 中 |
| **叙事连贯** | 故事逻辑/节奏控制 | 🟡 中 |
| **音频同步** | 配音/音效/画面同步 | 🟢 低 |

### 角色一致性失效类型

| 失效类型 | 描述 | 严重度 | 可察觉度 |
|---------|------|--------|---------|
| 面部漂移 | 面部特征逐渐变化 | 高 | 立即察觉 |
| 服装变化 | 服装细节/颜色改变 | 中 | 相邻镜头明显 |
| 身材变化 | 身高/体型/姿势变化 | 中 | 全身镜头明显 |
| 发型变化 | 长度/样式/颜色变化 | 高 | 首先被注意 |
| 肤色变化 | 肤色/妆容变化 | 中 | 特写镜头明显 |
| 配饰丢失 | 眼镜/首饰消失 | 高 | 立即察觉 |

#### 参考图像系统

| 模型 | 方法 | 参考图数量 | 一致性评分 |
|------|------|-----------|-----------|
| **Kling 3.0** | Character ID | 最多 5 张 | 9.0/10 ⭐ |
| **Seedance 2.0** | Face Lock | 1-3 张 | 8.5/10 |
| **Runway Gen-4** | Character Reference | 1-4 张 | 8.0/10 |
| **Veo 3** | Identity Preservation | 1-3 张 | 8.5/10 |
| **Wan 2.6** | Image Conditioning | 1 张 | 7.0/10 |

#### 最佳实践 (Kling 3.0 Character ID)

```
工作流程:
1. 上传 3-5 张角色参考图
2. 模型提取身份嵌入 (面部特征/体型/特征)
3. 每次生成都应用该嵌入
4. 保持 90%+ 镜头一致性

失败场景:
- 极端角度
- 极暗光线
- 角色在画面中很小
```

### 3. 长视频工作流

#### 15 分钟视频制作流程

```
Phase 1: 剧本和分镜规划 (Day 1)
- 15 分钟视频 = 40-80 个镜头
- 每个镜头 5-10 秒
- 创建详细镜头清单

Phase 2: 参考图创建 (Day 1-2)
- 主角：10-15 张图 (2-3 小时)
- 配角：5-8 张图/人 (1-2 小时)
- 场景：3-5 张图/场景 (30-60 分钟)
- 道具：2-3 张图/道具 (15-30 分钟)

Phase 3: 批量生成 (Day 2-4)
- 按相似度分批 (非按时间顺序)
- 每镜头生成 2-3 个版本
- 60 镜头 × 3 版本 = 180 次生成
- 成本：$18-54

Phase 4: 一致性审查 (Day 4-5)
- 并排对比相邻镜头
- 顺序播放检查
- 15-25% 需要重新生成

Phase 5: 剪辑拼接 (Day 5-6)
- DaVinci Resolve / Premiere Pro
- 修剪不稳定帧 (首尾 0.5-1 秒)
- 添加转场 (交叉溶解 0.5-1 秒)
- 调色统一

Phase 6: 音频和最终处理 (Day 6-7)
- 配音 (自己录/ElevenLabs/HeyGen)
- 音效设计
- 背景音乐
- 字幕/图形
```

## 🔧 关键技术

### 1. 批量生成策略

**按相似度分批** (非按时间顺序):

```
Batch 1: 所有主角正面特写
Batch 2: 所有主角 3/4 侧面
Batch 3: 所有主角全身镜头
Batch 4: 所有配角镜头
Batch 5: 所有环境/空镜头
Batch 6: 所有过渡/B-roll

原理:
相似镜头连续生成，模型输出更一致
避免在差异大的场景间切换
```

### 2. 转场技巧 (隐藏不一致)

| 技巧 | 适用场景 | 描述 |
|------|---------|------|
| 交叉溶解 | 场景变化 | 0.5-1 秒溶解掩盖角色变化 |
| 动作剪辑 | 同场景剪辑 | 角色运动时剪辑 (观众追踪动作) |
| 插入镜头 | 打破长场景 | 切到细节/B-roll |
| 快速摇摄 | 能量转场 | 快速相机运动隐藏接缝 |
| 匹配剪辑 | 风格转场 | 匹配构图/动作 |
| 淡出黑场 | 章节分隔 | 干净分隔重置预期 |

### 3. 种子锁定

```
当模型支持种子指定时:
- 为相关镜头批次锁定相同种子
- 相同种子 + 相似提示 = 更一致输出
- 适用于同一场景的多个镜头
```
