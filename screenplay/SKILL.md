# 专业短剧剧本创作 🎬📝

为 AI 视频生成提供专业的短剧剧本，确保故事性、节奏感、可执行性。

---

## 核心理念

AI 生成的短剧常犯的错误：
1. **流水账** — 一堆场景拼凑，没有故事内核
2. **无冲突** — 一切顺利，没有张力
3. **无弧光** — 角色从头到尾没有变化
4. **节奏平** — 每段一样强度，没有高潮低谷

**好的短剧 = 冲突 + 变化 + 情绪曲线**

---

## 三幕式结构（适配 1-3 分钟短剧）

| 幕 | 占比 | 时长 | 功能 | 情绪 |
|----|------|------|------|------|
| **第一幕：铺垫** | 25% | 15-25s | 介绍角色/世界/日常 → 触发事件 | 平静 → 好奇 |
| **第二幕：对抗** | 50% | 30-60s | 遭遇困难/挑战 → 尝试失败 → 发现转机 | 紧张 → 绝望 → 希望 |
| **第三幕：解决** | 25% | 15-25s | 最终决战 → 角色成长 → 新平衡 | 高潮 → 释然/温暖 |

## 剧本输出格式

### Markdown 格式（供人阅读）

```markdown
# 《片名》

**类型**: 冒险 / 治愈 / 科幻
**时长**: 2 分钟
**风格**: 3D皮克斯动画
**核心主题**: 用一句话概括故事内核

## 角色表
- 角色A: 一句话描述（外貌+性格+目标）
- 角色B: 一句话描述

## 故事梗概
一段话概括整个故事

## 分镜脚本

### 第一幕：铺垫 (0:00 - 0:25)

#### 镜头1 [5s] — 标题：日常
- **景别**: 全景
- **运动**: 缓慢推进
- **画面**: 详细描述
- **情绪**: 平静、温暖
- **音频**: 环境音描述 / 台词 / 无
- **转场**: 到下一镜的方式

### 第二幕：对抗 (0:25 - 1:25)
...

### 第三幕：解决 (1:25 - 2:00)
...
```

### JSON 格式（供程序调用）

```json
{
  "title": "片名",
  "genre": "冒险/治愈",
  "duration_seconds": 120,
  "style": "3D皮克斯动画",
  "theme": "故事内核一句话",
  "characters": [
    {
      "name": "角色名",
      "appearance": "外貌描述（用于视频 prompt）",
      "personality": "性格关键词",
      "goal": "角色目标"
    }
  ],
  "acts": [
    {
      "act": 1,
      "name": "铺垫",
      "start_time": 0,
      "end_time": 25,
      "emotion_arc": "平静→好奇",
      "shots": [
        {
          "shot_number": 1,
          "duration": 5,
          "title": "日常",
          "shot_type": "全景",
          "camera_movement": "缓慢推进",
          "visual_prompt": "用于视频生成的英文 prompt",
          "audio": "环境音/台词/无",
          "transition": "到下一镜",
          "reference_images": ["角色图", "场景图"]
        }
      ]
    }
  ]
}
```

## 创作规则

### 1. 每个镜头必须有变化
- 不能只描述"角色在做什么"
- 必须包含**情绪变化**或**信息揭示**

### 2. 每 15 秒必须有一个"钩子"
- 新发现、意外事件、情绪转折
- 防止观众注意力流失

### 3. 角色必须有弧光
- 开始时的状态 vs 结束时的状态 必须有变化
- 哪怕是微小的情绪变化也可以

### 4. 视频生成友好
- 每个镜头的 visual_prompt 用**英文**写
- 包含：景别 + 主体 + 动作 + 环境 + 光影 + 情绪
- 避免抽象描述（"他感到孤独" → "他独自坐在空荡荡的房间里，低头看着手中的照片"）

### 5. 音频规划
- 每段标注需要的音频类型：配音 / 环境音 / 音乐 / 无
- 配音文本单独列出，用于 TTS 生成
- 环境音描述用于 wan2.7 原生音频

## 快速创作模板

调用方式：
```
/screenplay --title "标题" --duration 120 --genre "冒险/治愈" --characters "角色描述" --theme "核心主题"
```

AI 按以下流程输出：
1. **故事核** — 一句话概括
2. **三幕大纲** — 每幕一句话
3. **角色表** — 外貌+性格+目标
4. **分镜脚本** — 逐镜描述（含英文 prompt）
5. **音频清单** — 需要 TTS 的台词列表
6. **参考图清单** — 需要生成的场景/道具设定图

## 经典短剧结构库

### 结构 1: 发现之旅
日常 → 发现异常 → 探索 → 遇到危险 → 逃脱/解决 → 带回收获

### 结构 2: 友谊
孤独 → 遇见 → 磨合（冲突） → 共同经历 → 分离/重逢 → 羁绊

### 结构 3: 成长
弱小 → 受挫 → 学习 → 再试 → 成功 → 蜕变

### 结构 4: 反转
正常 → 异常 → 追查 → 真相大白 → 世界翻转 → 新认知

### 结构 5: 循环
开始 → 经历 → 回到起点 → 但已不同

---

## 注意事项

- 每个镜头不超过 15 秒（Wan 2.7 限制）
- 角色外观描述在所有镜头中保持一致
- 场景设定图（房间、飞船、星球）需要单独生成作为参考图
- 台词控制在每句 10 字以内（TTS 自然度最佳）
